**Ubuntu Software**（ABN：95 595 575 880）致力于保护您的隐私。本政策说明了当您访问我们的网站和使用我们的软件工具时，我们如何处理相关信息。

## 我们收集的信息

### 网站

我们的网站 www.ubuntusoftware.net 是静态网站。我们不会：

- 通过网站收集个人信息
- 使用跟踪 Cookie
- 要求用户注册账户或登录
- 在我们的服务器上存储任何用户数据

### 软件工具

我们的命令行工具（CLI）完全在您的本地设备上运行。当您使用我们的工具连接到 Google Workspace 等第三方服务时，所有数据处理均在您的本地计算机上进行。

## Google API 服务的使用

我们的软件工具与 Google API 集成，以提供生产力功能。本节说明我们如何依照 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy) 处理 Google 用户数据。

### 我们访问的数据

当您授权我们的工具连接到您的 Google 账户时，我们可能会访问：

- **Gmail：** 邮件发送功能（撰写和发送电子邮件）
- **Google 日历：** 查看和创建日历活动
- **Google 云端硬盘：** 列出、上传、下载和管理文件
- **Google 表格：** 读取和写入电子表格数据
- **Google 文档：** 读取和写入文档内容
- **Google 幻灯片：** 读取和创建演示文稿

### 我们如何使用您的数据

您的 Google 数据**仅**用于：

- 执行您通过我们的 CLI 工具明确发出的命令
- 显示您请求的信息（日历活动、文件等）
- 在您指示工具执行时发送电子邮件或创建内容

**我们不会：**

- 将您的 Google 数据存储在任何外部服务器上
- 将您的数据传输给第三方
- 将您的数据用于广告或营销
- 出于执行您的命令以外的任何目的分析您的数据
- 在命令执行完成后保留您的数据

### 数据存储与保留

- **OAuth 令牌**存储在您本地设备的主目录中
- **您的 Google 数据**永远不会被持久存储——仅在命令执行期间保存在内存中
- 您可以随时通过 [Google 账户设置](https://myaccount.google.com/permissions) 撤销访问权限

### 有限使用披露

我们对从 Google API 获取的信息的使用和传输遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的有限使用要求。

具体而言：

1. 我们仅将 Google 用户数据用于提供或改进面向用户的功能
2. 除非为提供功能所必需、获得用户同意或出于法律原因，我们不会将 Google 用户数据转让给他人
3. 我们不会将 Google 用户数据用于广告
4. 除非获得用户同意、出于安全目的或为遵守法律，我们不允许任何人员阅读 Google 用户数据

## 托管与第三方服务

我们的网站托管在 **Cloudflare Pages** 上。Cloudflare 可能出于安全和性能目的收集标准的 Web 服务器日志（IP 地址、浏览器类型、访问的页面）。有关其数据处理方式的详细信息，请参阅 [Cloudflare 隐私政策](https://www.cloudflare.com/privacy/)。

## Cookie

我们不使用 Cookie 进行跟踪或投放广告。现有的任何 Cookie 均严格用于功能目的（例如 Cloudflare 出于安全需要所使用的 Cookie）。

## 您的权利

### GDPR（欧盟）

如果您位于欧盟，您享有《通用数据保护条例》（GDPR）规定的权利，包括：

- **访问权**——要求获取有关您的任何数据的信息
- **删除权**——要求删除任何个人数据
- **更正权**——要求更正不准确的数据
- **反对权**——反对对您的数据进行处理
- **数据可携带权**——以可携带的格式获取您的数据

### Google 数据权利

对于通过 Google API 访问的数据：

- **访问控制：** 您可以通过 OAuth 授权同意流程控制我们的工具可以访问哪些 Google 服务
- **撤销：** 您可以随时通过 [Google 账户设置](https://myaccount.google.com/permissions) 撤销我们的访问权限
- **透明度：** 我们的工具会准确显示其对您的数据执行的操作

## 数据安全

我们采取了适当的安全措施：

- OAuth 令牌以受限的文件权限存储（仅您的用户账户可读取）
- 与 Google API 的所有通信均使用 HTTPS 加密
- 不会将任何数据传输到我们的服务器
