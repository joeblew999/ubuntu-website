## 安全源于设计

我们不是为了通过审计而事后附加安全控制措施。我们构建的架构从根本上消除了攻击面。

**结果：** 需要审计的内容更少，合规因此变得更简单。

---

## 自主主权架构

| 原则 | 含义 |
|-----------|---------------|
| **无回传** | 零遥测。不跟踪使用情况。不向外部服务器回传数据。 |
| **支持物理隔离** | 无需互联网连接即可使用全部功能。 |
| **数据永不外流** | 您的数据始终保留在您自己的基础设施上。 |
| **单一审计范围** | 无需调查任何第三方云服务提供商。 |
| **无供应链风险** | 依赖极少。单一二进制文件部署。 |

---

## 让合规更简单

在各大主流合规框架下，自主主权架构都能降低审计的复杂度：

| 框架 | 适用对象 | 自主主权架构的优势 |
|-----------|--------------|-------------------------|
| **SOC 2 Type II** | 企业 B2B | 攻击面更小。审计范围更简单。审计更快。 |
| **FedRAMP** | 美国政府 | 政府机构倾向于隔离部署。完全的数据主权。 |
| **HIPAA** | 医疗保健 | 无需与外部签订 BAA。ePHI 始终不离开您的系统。 |
| **PCI DSS** | 金融服务 | 加密密钥由您掌控。没有云端中间方。 |
| **ISO 27001** | 国际 | 需要记录和监控的外部依赖更少。 |
| **IEC 62443** | 制造业 | 满足工业控制系统对物理隔离安全等级的要求。 |
| **GDPR/CCPA** | 数据隐私 | 无跨境数据传输。支持数据驻留要求。 |

## 技术栈

我们的安全不只停留在策略层面，而是体现在每一项技术选型中：

| 组件 | 安全优势 |
|-----------|------------------|
| **OpenBSD** | 面向关键部署、以安全为核心的操作系统 |
| **Go** | 内存安全的编译型二进制文件（无运行时漏洞） |
| **NATS JetStream** | mTLS 加密，零信任消息传递 |
| **单一二进制文件** | 没有依赖链。没有供应链攻击。 |

## 部署选项

选择符合您需求的安全级别：

| 部署方式 | 使用场景 | 安全态势 |
|------------|----------|------------------|
| **云端** | 开发、演示 | 标准控制 |
| **本地部署** | 企业、受监管行业 | 增强隔离 |
| **物理隔离** | 政府、关键基础设施 | 最高安全级别 |

所有部署方式使用同一套代码库。追求更高的安全级别，无需在功能上做任何妥协。
