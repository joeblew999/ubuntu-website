## ソフトウェアアーキテクチャ

すべてのソフトウェアコンポーネントは、責任範囲が明確なオープンソースコードで動作します。このスタックは、リモート管理、OTA（Over-the-Air）アップデート、そして1,000台以上の機体にわたる一貫した動作を実現するよう設計されています。

---

## フライトコントローラー：Pixhawk

### PX4 v1.14 LTS

フライトコントローラーでは **PX4 Autopilot v1.14 LTS** が動作します：

| 項目 | 詳細 |
|--------|---------|
| **バージョン** | v1.14.x LTS（長期サポート） |
| **サポート期間** | 2年以上にわたるセキュリティ修正および重大な修正 |
| **構成** | フリート全体で標準化されたパラメータ |
| **アップデート** | QGroundControl または MAVLink 経由 |

**LTSを採用する理由：**

- **安定性** — 本番環境で検証済みのコードベースで、変更が最小限
- **セキュリティ** — 機能変更なしで重大な脆弱性にパッチを適用
- **予測可能性** — フリート全体で動作が把握済み
- **サポート** — Dronecode エコシステムから商用サポートを利用可能

**主要モジュール：**

- **EKF2** — 状態推定のための拡張カルマンフィルター
- **Position Controller** — マルチコプターの位置および速度制御
- **Navigator** — ミッション実行、RTL、ジオフェンス
- **Commander** — ステートマシン、フェイルセーフ処理
- **MAVLink** — テレメトリおよびコマンドプロトコル

## センサーコンパニオン：Raspberry Pi

### Ubuntu Server 22.04 LTS

Raspberry Pi では **Ubuntu Server 22.04** が動作します：

| 項目 | 詳細 |
|--------|---------|
| **ディストリビューション** | Ubuntu Server 22.04 LTS |
| **カーネル** | Pi 用パッチを適用したメインライン Linux |
| **Init システム** | systemd |
| **サポート期間** | 2027年4月まで |

**Raspberry Pi OS ではなく Ubuntu Server を採用する理由：**

- **一貫性** — Pi と Jetson で同じ OS
- **パッケージ管理** — 標準の apt リポジトリ、snap も利用可能
- **LTS サポート** — 5年間のセキュリティアップデート
- **ツール** — 運用チームにとって馴染みのある管理手法

### コアサービス

| サービス | 目的 |
|---------|---------|
| **mavlink-router** | FCU と Jetson 間の MAVLink メッセージルーティング |
| **sensor-agent** | 環境センサーデータの収集 |
| **gpsd** | 位置データ用の GPS/GNSS デーモン |
| **chrony** | NTP 時刻同期 |

**mavlink-router** は極めて重要です。Pixhawk のシリアルポートからの MAVLink トラフィックを UDP 経由で Jetson に転送し、Vehicle Gateway がテレメトリを処理できるようにします。

## AIコンパニオン：Jetson

### JetPack 6.x

Jetson では **NVIDIA JetPack 6.x** が動作します：

| コンポーネント | バージョン |
|-----------|---------|
| **L4T（Linux for Tegra）** | Ubuntu 22.04 ベース |
| **CUDA** | 12.x |
| **cuDNN** | 8.x |
| **TensorRT** | 8.x |
| **VPI（Vision Programming Interface）** | 3.x |

**JetPack 6 を採用する理由：**

- **最新の Orin サポート** — Orin ファミリーでの完全なハードウェアアクセラレーション
- **Ubuntu 22.04 ベース** — Pi と揃えることで一貫した運用が可能
- **コンテナサポート** — 分離されたワークロード向けの NVIDIA Container Runtime
- **OTA アップデート** — フリート全体のファームウェア更新のための NVIDIA ツール

### CUDA + TensorRT

AI 推論は **TensorRT** ランタイムを通じて実行されます：

- **モデル最適化** — エッジ展開のための INT8/FP16 量子化
- **バッチ推論** — 複数フレームを効率的に処理
- **低レイテンシ** — GPU メモリへの直接アクセス

代表的なワークロード：

- 物体検出（YOLO、SSD）
- セマンティックセグメンテーション
- オプティカルフロー
- 深度推定

### ROS 2 Humble

**ROS 2 Humble Hawksbill** がロボティクスミドルウェアを提供します：

| 項目 | 詳細 |
|--------|---------|
| **ディストリビューション** | Humble Hawksbill |
| **サポート期間** | 2027年5月まで |
| **DDS** | CycloneDDS（デフォルト）または FastDDS |
| **ビルドシステム** | colcon |

**ROS 2 Humble を採用する理由：**

- **LTS リリース** — 5年間のサポートが Ubuntu/JetPack と一致
- **リアルタイム対応** — 決定論的な実行パスを利用可能
- **センサー統合** — 豊富なドライバーパッケージ
- **シミュレーション** — テスト用の Gazebo 統合

**主要パッケージ：**

| パッケージ | 目的 |
|---------|---------|
| **px4_msgs** | ROS 2 用の MAVLink メッセージ定義 |
| **px4_ros_com** | PX4-ROS 2 ブリッジ（uXRCE-DDS） |
| **image_transport** | カメラデータの処理 |
| **tf2** | 座標フレーム変換 |

## Vehicle Gateway

### Go による実装

**Vehicle Gateway** は、各 Jetson 上で動作するカスタム Go サービスです：

| 項目 | 詳細 |
|--------|---------|
| **言語** | Go 1.21+ |
| **依存関係** | nats.go、mavlink ライブラリ |
| **デプロイ** | systemd サービスまたはコンテナ |
| **構成** | 環境変数 + 設定ファイル |

**Go を採用する理由：**

- **単一バイナリ** — ランタイム依存関係がなく、デプロイが簡単
- **パフォーマンス** — 低レイテンシ、効率的なメモリ使用
- **並行処理** — MAVLink/NATS の並列処理に Goroutine を活用
- **NATS エコシステム** — 第一級の nats.go クライアントライブラリ

**責務：**

1. **MAVLink 取り込み** — mavlink-router から MAVLink メッセージを受信・解析
2. **状態のダウンサンプリング** — WAN 送信用にテレメトリレートを削減
3. **イベント抽出** — 状態遷移からイベントを生成
4. **コマンド実行** — NATS コマンドを受信・検証し、FCU へ送信
5. **シャドウ調整** — 目標状態と報告状態をフリートバックエンドと同期

## コントロールプレーン

### NATS + JetStream

フリートの連携は、**JetStream** による永続化を備えた **NATS** 上で動作します：

| コンポーネント | 役割 |
|-----------|------|
| **NATS Server** | コアとなる pub/sub メッセージング |
| **JetStream** | ストリームの永続化、KV ストア |
| **Leaf Nodes** | 機体ローカルの NATS インスタンス |
| **Hub Clusters** | 地域ごとの集約ポイント |

**NATS を採用する理由：**

- **パフォーマンス** — ノードあたり毎秒数百万メッセージ
- **シンプルさ** — 単一バイナリ、最小限の構成
- **永続化** — 永続ストリームと KV のための JetStream
- **トポロジー** — あらゆる規模に対応するリーフノード、クラスター、スーパークラスター

**フリートトポロジー：**

```
┌─────────────────────────────────────────────────────┐
│                   Global Hub (optional)             │
│                   NATS Supercluster                 │
└─────────────────┬───────────────────┬───────────────┘
                  │                   │
      ┌───────────▼───────┐ ┌─────────▼───────────┐
      │   Regional Hub A  │ │   Regional Hub B    │
      │   3-node cluster  │ │   3-node cluster    │
      └─────────┬─────────┘ └─────────┬───────────┘
                │                     │
    ┌───────────┼───────────┐         │
    │           │           │         │
┌───▼───┐ ┌─────▼───┐ ┌─────▼───┐ ┌───▼───┐
│ Leaf  │ │  Leaf   │ │  Leaf   │ │ Leaf  │
│ VID-1 │ │ VID-2   │ │ VID-3   │ │VID-N  │
└───────┘ └─────────┘ └─────────┘ └───────┘
```

各機体は、所属する地域ハブに接続する **リーフノード** を実行します。リーフノードはローカルの pub/sub を処理し、切断時にはストア・アンド・フォワードを行います。

## ソフトウェアアップデート戦略

### フリート全体の OTA

| コンポーネント | アップデート方式 |
|-----------|------------------|
| **PX4** | QGC またはカスタムツールによる MAVLink ファームウェアアップロード |
| **Pi/Ubuntu** | apt + unattended-upgrades、またはカスタムイメージのデプロイ |
| **Jetson/JetPack** | NVIDIA OTA ツール、コンテナのアップデート |
| **Vehicle Gateway** | systemd によるバイナリ置き換え、またはコンテナのアップデート |
| **NATS Leaf** | グレースフルリスタートを伴うバイナリアップデート |

**原則：**

- **段階的ロールアウト** — 一部を更新し、検証してから拡大
- **ロールバック機能** — 以前のバージョンを常に利用可能
- **ヘルスチェック** — 更新後の自動検証
- **ダウンタイムの最小化** — メンテナンス時間帯に更新を実施
