## 脆弱性開示ポリシー

Ubuntu Software は、当社の製品およびサービスのセキュリティ確保に努めています。潜在的な脆弱性を発見したセキュリティ研究者の皆様からのご報告を歓迎します。

---

## セーフハーバー

本ポリシーに従って実施されたセキュリティ研究について、当社は次のように扱います：

- **許可済み** — 当社はあなたに対して法的措置を取りません
- **有益** — 当社のセキュリティ向上へのあなたの貢献を高く評価します
- **保護対象** — 問題の理解と解決に向けて、あなたと協力します

調査の際に本ポリシーを遵守するよう誠実に努めた場合、当社があなたに対して法的措置を開始したり、それを推奨したりすることはありません。

---

## 対象範囲

本ポリシーは、Ubuntu Software のすべての製品およびサービスに適用されます：

| 対象 | 例 |
|----------|----------|
| **ウェブサイト** | www.ubuntusoftware.net |
| **Publish プラットフォーム** | パブリッシングおよびデザインツール |
| **Spatial プラットフォーム** | ロボティクスおよびシミュレーション |
| **API** | 公開 API エンドポイント |
| **オープンソース** | 当社の公開リポジトリ |

---

## 禁止行為

ユーザーとシステムを保護するため、以下の行為はお控えください：

- サービス妨害（DoS）攻撃
- 従業員または委託先に対するソーシャルエンジニアリング
- 物理的なアクセスの試み
- 他のユーザーに属するデータへのアクセスまたは改変
- サービス品質を低下させる自動脆弱性スキャン
- 当社が対応する時間を得る前の一般公開

## 報告方法

報告は[お問い合わせフォーム](/contact/?subject=security)から送信してください。

以下の情報を含めてください：

1. **説明** — どのような脆弱性ですか？
2. **場所** — どこで発見しましたか？（URL、コンポーネント、バージョン）
3. **影響** — 攻撃者はこれを使って何ができますか？
4. **手順** — どのように再現できますか？
5. **概念実証** — スクリーンショット、コード、またはログ（ある場合）

匿名でのご報告も可能です。個人情報は必要ありません。

[脆弱性を報告する →](/contact/?subject=security)
