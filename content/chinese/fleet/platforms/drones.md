## 面向机队规模无人机运营的硬件

机队运营要求硬件在性能与可维护性之间取得平衡。该技术栈中的每个组件都是基于生产可靠性、零部件可获得性以及现场可维修性而选定的。

---

## 协议：MAVLink

我们机队中的无人机使用 **MAVLink**（Micro Air Vehicle Link，微型飞行器链路）进行通信：

| 方面 | 详情 |
|--------|---------|
| **版本** | MAVLink 2.0 |
| **传输方式** | 串口（UART）、UDP、TCP |
| **消息速率** | 1-50Hz，取决于消息类型 |
| **加密** | MAVLink 2.0 签名（可选） |

**MAVLink 提供：**
- 标准化遥测数据（位置、姿态、电池、传感器）
- 指令协议（解锁、起飞、航点、返航 RTL）
- 参数管理
- 文件传输（日志、任务）

[车辆网关]({{< relref "/fleet/gateway" >}}) 将 MAVLink 消息转换为 NATS 主题，从而实现全机队范围的遥测数据汇聚和指令分发。

## 机架

### Holybro X500 V2 ARF

**Holybro X500 V2** 为机队部署提供了理想的平台：

| 规格 | 数值 |
|---------------|-------|
| **轴距** | 500mm |
| **机架重量** | 约 410g |
| **最大起飞重量** | 约 2kg |
| **续航时间** | 15-20 分钟（标准载荷下） |
| **电机安装孔距** | 16x16mm / 19x19mm |

**为什么选择 X500：**

- **成熟设计** — 全球已部署数千台，社区知识丰富
- **零部件可获得性** — 机臂、起落架和五金件随时可购
- **便于维护** — 模块化结构，可现场维修
- **载荷灵活** — 足以搭载双伴随计算机及传感器

ARF（Almost Ready to Fly，近乎可飞）套件包含机架、电机、电调和螺旋桨——减少了大规模机队中的组装差异。

## 飞控

### Pixhawk 6X

运行 **PX4 v1.14 LTS** 的 **Pixhawk 6X** 负责所有飞行关键功能：

| 规格 | 数值 |
|---------------|-------|
| **处理器** | STM32H753（480MHz Cortex-M7） |
| **IMU** | 三重冗余（ICM-42688-P、ICM-45686、BMI088） |
| **气压计** | 双气压计（MS5611、ICP-20100） |
| **磁力计** | IST8310 |
| **接口** | 3x CAN、6x UART、SPI、I2C、PWM |

**为什么选择 Pixhawk 6X：**

- **冗余** — 三重 IMU、双气压计，支持传感器表决
- **PX4 LTS 支持** — 长期稳定性与安全补丁
- **FMUv6X 标准** — 可与其他符合标准的飞控板互换
- **减振隔离** — 内置 IMU 减振

飞控负责：

- 姿态估计与控制
- 定点悬停与导航
- 失效保护行为（返航、降落、地理围栏）
- 遥控输入处理
- MAVLink 遥测

## 伴随计算机

机队载具运行**双伴随计算机**，各自承担不同职责：

### Raspberry Pi 4 / CM4（传感器伴随计算机）

负责轻量级传感器集成和数据采集：

| 规格 | 数值 |
|---------------|-------|
| **处理器** | 四核 Cortex-A72 @ 1.8GHz |
| **内存** | 4GB 或 8GB |
| **存储** | 32GB 以上 microSD 或 eMMC |
| **功耗** | 典型 5V @ 3A |

**职责：**

- 环境传感器驱动（温度、湿度、空气质量）
- GPS/GNSS 数据记录
- 相机采集（非 AI 工作负载）
- 向 Jetson 进行 MAVLink 路由
- Jetson 离线时进行存储转发

### NVIDIA Jetson（AI 伴随计算机）

负责计算密集型工作负载：

| 型号 | GPU 核心 | AI 性能 | 功耗 |
|-------|-----------|----------------|-------|
| **Jetson Orin Nano** | 1024 CUDA | 40 TOPS | 7-15W |
| **Jetson Orin NX** | 1024 CUDA | 100 TOPS | 10-25W |
| **Jetson AGX Orin** | 2048 CUDA | 275 TOPS | 15-60W |
| **Jetson Xavier NX** | 384 CUDA | 21 TOPS | 10-20W |

**职责：**

- 计算机视觉（目标检测、跟踪）
- 视觉惯性里程计
- 路径规划与避障
- 车辆网关（NATS 客户端）
- NATS 叶节点

机队部署通常使用 **Jetson Orin Nano** 进行高性价比推理，或使用 **Orin NX** 处理高要求的感知工作负载。

## 无线电系统

### 遥控：ExpressLRS

**ExpressLRS** 提供飞手接管链路：

| 规格 | 数值 |
|---------------|-------|
| **频率** | 915MHz（美国）/ 868MHz（欧盟） |
| **距离** | 10km 以上（取决于功率/天线） |
| **延迟** | <5ms |
| **协议** | 开源 |

**为什么选择 ExpressLRS：**

- **开源** — 无供应商锁定，社区驱动开发
- **距离** — 为视距内运行提供可靠链路
- **低延迟** — 需要时可实现灵敏的手动控制
- **成本** — 接收机价格实惠，适合机队规模部署

### 数传：SiK 电台

**SiK 915 MHz** 电台提供地面站遥测：

| 规格 | 数值 |
|---------------|-------|
| **频率** | 915MHz（美国）/ 433MHz（欧盟） |
| **距离** | 典型 1-2km |
| **数据速率** | 最高 250kbps |
| **接口** | 串口（UART） |

**在机队中的作用：**

- 蜂窝网络不可用时的备用遥测
- 地面控制站连接
- 本地测试与调试

在生产机队运营中，遥测数据主要通过 Jetson 的蜂窝连接传输至 NATS。SiK 电台用作备份及现场诊断。

## 电源系统

### 电池：4S LiPo

| 规格 | 数值 |
|---------------|-------|
| **配置** | 4S（标称 14.8V） |
| **容量** | 典型 5000-6000mAh |
| **放电倍率** | 30C 以上 |
| **接头** | XT60 |

**机队注意事项：**

- 统一采用单一电池配置，便于后勤管理
- 条件允许时使用带遥测功能的智能电池
- 实施电池轮换与健康状态跟踪
- 为连续运营按 3:1 的电池与载具比例进行规划

### 配电

- **PDB/PMS** — 为伴随计算机供电的电源管理板
- **BEC** — 为 Pi、舵机提供 5V 稳压电源
- **Jetson 供电** — 由电池经稳压器直接供电（典型 12V）

## 连接

### 蜂窝网络：4G/5G + eSIM

每台 Jetson 通过蜂窝模组联网：

| 规格 | 数值 |
|---------------|-------|
| **模组** | Quectel RM520N-GL 或类似型号 |
| **频段** | 4G LTE + 5G NR |
| **SIM** | 支持 OTA 配置的 eSIM |
| **接口** | USB 3.0 或 M.2 |

**eSIM 优势：**

- 大规模机队中无需更换实体 SIM 卡
- 远程运营商配置
- 切换运营商以优化覆盖
- 集中式订阅管理

## 安全模型

无人机专属安全功能在多个层级上强制执行：

| 层级 | 机制 | 行为 |
|-------|-----------|----------|
| **遥控接管** | ExpressLRS | 飞手始终拥有手动控制权 |
| **飞控** | PX4 失效保护 | 返航、降落、地理围栏强制执行 |
| **伴随计算机** | 车辆网关 | 指令验证、安全检查 |
| **网络** | NATS 绝不进入控制回路 | 仅用于监控，不承担飞行关键功能 |

完整的安全架构请参见[安全模型]({{< relref "/fleet/safety" >}})。
