## Linux 专业能力，跨平台交付。

Ubuntu Software 在 Linux 上构建系统已有数十年，远早于 Ubuntu Linux 的诞生。我们的部署覆盖所有平台：Linux 服务器、嵌入式系统、Windows、Mac、iOS、Android。

---

## Ubuntu 之名

Ubuntu 一词源自南非哲学，意为“我之所以为我，是因为我们”。早在 Canonical 于 2004 年将同一个词用作其 Linux 发行版名称之前多年，我们就已选用了这个名字。

一个美妙的巧合：在同样的数十年里，我们一直在构建运行于 Linux 和开源平台上的软件。这一理念与我们完美契合：软件连接人、系统与思想。

**在寻找 Ubuntu Linux？** 如果您需要的是 Linux 专业能力，那么您来对地方了，只不过我们不是那个发行版。我们构建的软件可运行于 Ubuntu Linux、Debian、RHEL 以及所有其他主流发行版。

## Linux 传承

### 服务器与桌面 Linux

数十年来在 Linux 上运行的生产系统：

- **企业服务器**：为全球性组织打造的高可用系统
- **桌面应用**：原生 Linux 图形界面，而非简单的 Web 封装
- **开发基础设施**：CI/CD、容器化、编排

### 嵌入式 Linux

面向工业和物联网应用的实时系统：

- **机器人**：在嵌入式 Linux 上运行 Viam RDK，用于自主系统
- **工业控制**：工厂自动化、传感器网络
- **边缘计算**：在设备端进行处理，而不仅依赖云端

### OpenBSD

当安全性不容妥协时：

- **政府系统**：满足涉密要求的部署
- **金融基础设施**：不容许任何安全漏洞的系统
- **物理隔离环境**：无法接入互联网的网络

## 可扩展架构

### 无单点故障（SPOF）

每个组件都有冗余。任何单一服务器、服务或数据中心都无法导致整个系统瘫痪。

### 无单点性能瓶颈（SPOP）

计算能力可水平扩展。通过增加节点来提升容量，而不是购买更大的服务器。

### 数百个数据中心

专为全球分布而设计的架构：

- 部署在靠近用户的位置，实现低延迟
- 通过复制实现冗余
- 在网络分区时独立运行

### 部署灵活性

随处运行：

| 选项 | 使用场景 |
|--------|----------|
| **二进制文件** | 单文件部署，依赖极少 |
| **Docker** | 容器化、可复现的环境 |
| **Kubernetes** | 编排式、自动扩缩容的集群 |
| **本地部署** | 您的硬件，由您掌控 |
| **物理隔离** | 无法访问互联网的网络 |

## 为何重要

大多数“跨平台”解决方案都是妥协的产物：用 Electron 封装的 Web 应用，用起来不像原生的移动应用，只能在一个操作系统上真正好用的桌面应用。

我们构建的软件：

- **随处运行**：Linux、Windows、Mac、iOS、Android、嵌入式
- **原生体验**：而不是伪装成应用的网页
- **无限扩展**：无单点故障，无单点性能瓶颈
- **随处部署**：云端、本地、物理隔离、边缘

数十年经验，经全球规模验证，随时为您的项目提供支持。
