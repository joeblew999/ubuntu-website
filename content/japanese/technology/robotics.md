## ロボティクススタック

設計からデプロイまで。Spatial は 3D 設計とシミュレーションのレイヤーを提供します。Viam RDK は実際のロボットを制御・運用するためのランタイムを提供します。

---

## 組み込み Linux ランタイム

ロボティクスは Linux 上で動作します。私たちは Linux と組み込みシステムにおける数十年の経験を活かし、工場の現場、屋外環境、リソースの限られたエッジデバイスといった現実の環境に向けて開発しています。

### Viam RDK ランタイム

**Viam RDK を選んだ理由：**

- **オープンソース** — 私たちのオープンスタンダードの理念に合致
- **Go ネイティブ** — 私たちの技術スタックに適合
- **モジュール式** — コンポーネントの交換や拡張が可能
- **クラウドはオプション** — 私たちの製品と同様に、オフラインファーストで動作
- **ハードウェア非依存** — 特定のロボットメーカーに縛られない
- **組み込み Linux で動作** — Raspberry Pi、NVIDIA Jetson、産業用コントローラー

Viam RDK は、言語に依存しない SDK（Go、Python、TypeScript）とモジュール式のコンポーネントアーキテクチャを備えたオープンソースのロボティクス開発キットです。

[Viam RDK ドキュメント →](https://docs.viam.com/)

### 組み込みプラットフォーム

| プラットフォーム | ユースケース |
|----------|----------|
| **Raspberry Pi** | プロトタイピング、エッジコンピューティング、キオスク |
| **NVIDIA Jetson** | GPU による高速なビジョン処理と機械学習 |
| **産業用 Linux** | 工場自動化、過酷な環境 |
| **カスタム ARM ボード** | 用途特化型のデプロイ |

同じ Go コードベース。同じ Viam RDK。開発用ワークステーションから組み込みエッジデバイスまでデプロイできます。

## ビジョンと認識

### カメラの抽象化

Viam は、Web カメラ、IP カメラ、LiDAR、Intel RealSense D435i などの深度カメラといった多様な種類のカメラで動作する統一された `rdk:component:camera` API を提供します。

**仕組み：**

- **標準化された API** — コードはハードウェアではなく Viam のカメラインターフェースとやり取りします
- **組み込みドライバー** — `viam-camera-realsense` モジュールが RealSense との統合を処理します
- **ハードウェア非依存** — アプリケーションロジックを変更せずにカメラを交換できます
- **設定駆動** — 解像度、センサー、ストリームはコードではなく JSON で設定します

利用可能なメソッド：`GetImage()`、`GetImages()`、`GetPointCloud()`、およびカメラの内部パラメーター。

### Intel RealSense D435i

点群生成と空間認識のための RGB-D 深度センシング。

[GitHub の librealsense →](https://github.com/realsenseai/librealsense)

### ML パイプライン

- YOLOv8 による物体検出とセグメンテーション
- Viam vision サービスとの統合
- エッジデバイス上でのリアルタイム推論

## ハードウェアの抽象化

**最大の価値：コードではなく設定を変えるだけ。**

- **同じソフトウェアで、より大きなアームへ** — xArm の設定を UR5e や KUKA に差し替えて再デプロイ
- **xArm をティーチングペンダントとして活用** — xArm で動作を実演し、より大きなアームがそれを再現
- **複数ロボットの協調** — xArm が小型部品を、KUKA が重量物を担当
- **デジタルツイン開発** — xArm を対象に開発し、KUKA の運動学でシミュレーション
