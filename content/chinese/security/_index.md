## 漏洞披露政策

Ubuntu Software 致力于保障我们产品和服务的安全。我们欢迎发现潜在漏洞的安全研究人员向我们报告。

---

## 安全港

我们认为，按照本政策开展的安全研究属于：

- **已授权** — 我们不会对您采取法律行动
- **有益的** — 我们重视您为提升我们的安全性所做的贡献
- **受保护** — 我们将与您合作，了解并解决问题

如果您在研究过程中本着诚信原则努力遵守本政策，我们不会对您提起或建议提起法律诉讼。

---

## 适用范围

本政策适用于 Ubuntu Software 的所有产品和服务：

| 适用范围 | 示例 |
|----------|----------|
| **网站** | www.ubuntusoftware.net |
| **发布平台** | 发布和设计工具 |
| **空间平台** | 机器人与仿真 |
| **API** | 公共 API 端点 |
| **开源** | 我们的公共代码仓库 |

---

## 禁止的活动

为保护我们的用户和系统，请勿进行以下活动：

- 拒绝服务攻击
- 对员工或承包商进行社会工程攻击
- 尝试物理访问
- 访问或修改属于其他用户的数据
- 导致服务降级的自动化漏洞扫描
- 在我们有时间回应之前公开披露

---

## 如何报告

请使用我们的[联系表单](/contact/?subject=security)提交您的报告。

请包含以下内容：

1. **描述** — 漏洞是什么？
2. **位置** — 您在哪里发现的？（URL、组件、版本）
3. **影响** — 攻击者可以利用它做什么？
4. **步骤** — 我们如何复现该问题？
5. **概念验证** — 截图、代码或日志（如有）

您可以匿名报告。我们不要求提供个人信息。

[报告漏洞 →](/contact/?subject=security)

---

## 我们的承诺

| 行动 | 时间 |
|--------|----------|
| **确认收到** | 3 个工作日内 |
| **初步评估** | 10 个工作日内 |
| **状态更新** | 每 30 天一次，直至问题解决 |
| **目标解决时间** | 90 天（行业标准） |

我们会随时向您通报进展，并在问题修复后通知您。

我们目前不提供金钱奖励，但我们感谢您为提升我们产品安全性所做的贡献。
