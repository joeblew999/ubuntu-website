## フリート規模のドローン運用向けハードウェア

フリート運用には、性能と保守性を両立したハードウェアが欠かせません。このスタックの各コンポーネントは、本番環境での信頼性、部品の入手しやすさ、現場での整備のしやすさを基準に選定しています。

---

## プロトコル：MAVLink

当社フリートのドローンは、**MAVLink**（Micro Air Vehicle Link）を使用して通信します：

| 項目 | 詳細 |
|--------|---------|
| **バージョン** | MAVLink 2.0 |
| **トランスポート** | シリアル（UART）、UDP、TCP |
| **メッセージレート** | メッセージの種類に応じて1〜50Hz |
| **暗号化** | MAVLink 2.0 署名（オプション） |

**MAVLinkの機能：**
- 標準化されたテレメトリ（位置、姿勢、バッテリー、センサー）
- コマンドプロトコル（アーム、離陸、ウェイポイント、RTL）
- パラメータ管理
- ファイル転送（ログ、ミッション）

[Vehicle Gateway]({{< relref "/fleet/gateway" >}})はMAVLinkメッセージをNATSサブジェクトに変換し、フリート全体でのテレメトリ集約とコマンド配信を可能にします。

## 機体フレーム

### Holybro X500 V2 ARF

**Holybro X500 V2**は、フリート展開に最適なプラットフォームです：

| 仕様 | 値 |
|---------------|-------|
| **ホイールベース** | 500mm |
| **フレーム重量** | 約410g |
| **最大離陸重量** | 約2kg |
| **飛行時間** | 15〜20分（標準ペイロード搭載時） |
| **モーターマウント** | 16x16mm / 19x19mm |

**X500を選ぶ理由：**

- **実績のある設計** — 世界中で数千台が稼働しており、コミュニティの知見も豊富
- **部品の入手性** — アーム、ランディングギア、各種ハードウェアをすぐに入手可能
- **保守しやすい** — モジュール構造で、現場での整備が可能
- **ペイロードの柔軟性** — 2台のコンパニオンコンピュータとセンサーを搭載できる十分な積載量

ARF（Almost Ready to Fly）キットにはフレーム、モーター、ESC、プロペラが含まれており、大規模フリート全体で組み立てのばらつきを抑えられます。

## フライトコントローラー

### Pixhawk 6X

**PX4 v1.14 LTS**を搭載した**Pixhawk 6X**が、飛行に不可欠なすべての機能を担います：

| 仕様 | 値 |
|---------------|-------|
| **プロセッサ** | STM32H753（480MHz Cortex-M7） |
| **IMU** | 三重冗長（ICM-42688-P、ICM-45686、BMI088） |
| **気圧計** | デュアル（MS5611、ICP-20100） |
| **磁気センサー** | IST8310 |
| **インターフェース** | CAN x3、UART x6、SPI、I2C、PWM |

**Pixhawk 6Xを選ぶ理由：**

- **冗長性** — 三重IMUとデュアル気圧計によるセンサー多数決
- **PX4 LTSサポート** — 長期的な安定性とセキュリティパッチ
- **FMUv6X規格** — 他の準拠ボードと互換性あり
- **防振** — IMUダンピングを内蔵

フライトコントローラーの担当機能：

- 姿勢推定と制御
- 位置保持とナビゲーション
- フェイルセーフ動作（RTL、着陸、ジオフェンス）
- RC入力処理
- MAVLinkテレメトリ

## コンパニオンコンピュータ

フリートの機体は、役割の異なる**2台のコンパニオンコンピュータ**を搭載しています：

### Raspberry Pi 4 / CM4（センサーコンパニオン）

軽量なセンサー統合とデータ収集を担当します：

| 仕様 | 値 |
|---------------|-------|
| **プロセッサ** | クアッドコア Cortex-A72 @ 1.8GHz |
| **RAM** | 4GBまたは8GB |
| **ストレージ** | 32GB以上のmicroSDまたはeMMC |
| **電源** | 5V @ 3A（標準） |

**担当機能：**

- 環境センサードライバー（温度、湿度、空気質）
- GPS/GNSSデータのロギング
- カメラ撮影（AI以外の処理）
- JetsonへのMAVLinkルーティング
- Jetsonがオフラインの間のストア・アンド・フォワード

### NVIDIA Jetson（AIコンパニオン）

計算負荷の高い処理を担当します：

| モデル | GPUコア | AI性能 | 消費電力 |
|-------|-----------|----------------|-------|
| **Jetson Orin Nano** | 1024 CUDA | 40 TOPS | 7〜15W |
| **Jetson Orin NX** | 1024 CUDA | 100 TOPS | 10〜25W |
| **Jetson AGX Orin** | 2048 CUDA | 275 TOPS | 15〜60W |
| **Jetson Xavier NX** | 384 CUDA | 21 TOPS | 10〜20W |

**担当機能：**

- コンピュータビジョン（物体検出、追跡）
- ビジュアル・イナーシャル・オドメトリ
- 経路計画と障害物回避
- Vehicle Gateway（NATSクライアント）
- NATSリーフノード

フリート展開では、コスト効率の高い推論には**Jetson Orin Nano**、高負荷な認識処理には**Orin NX**を使用するのが一般的です。

## 無線システム

### RC制御：ExpressLRS

**ExpressLRS**は、パイロットによるオーバーライド用リンクを提供します：

| 仕様 | 値 |
|---------------|-------|
| **周波数** | 915MHz（米国）/ 868MHz（EU） |
| **通信距離** | 10km以上（出力やアンテナによる） |
| **遅延** | 5ms未満 |
| **プロトコル** | オープンソース |

**ExpressLRSを選ぶ理由：**

- **オープンソース** — ベンダーロックインがなく、コミュニティ主導で開発
- **通信距離** — 目視内飛行に十分な信頼性の高いリンク
- **低遅延** — 必要なときに応答性の高い手動操縦が可能
- **コスト** — フリート規模でも手頃な価格の受信機

### テレメトリ：SiK無線

**SiK 915 MHz**無線機が地上局とのテレメトリ通信を担います：

| 仕様 | 値 |
|---------------|-------|
| **周波数** | 915MHz（米国）/ 433MHz（EU） |
| **通信距離** | 通常1〜2km |
| **データレート** | 最大250kbps |
| **インターフェース** | シリアル（UART） |

**フリートでの役割：**

- セルラー通信が使えない場合のバックアップテレメトリ
- 地上管制局との接続
- ローカルでのテストとデバッグ

本番のフリート運用では、テレメトリは主にJetsonのセルラー接続を経由してNATSに送られます。SiK無線はバックアップ用と現場での診断用です。

## 電源システム

### バッテリー：4S LiPo

| 仕様 | 値 |
|---------------|-------|
| **構成** | 4S（公称14.8V） |
| **容量** | 通常5000〜6000mAh |
| **放電レート** | 30C以上 |
| **コネクタ** | XT60 |

**フリート運用での考慮事項：**

- ロジスティクスのため、バッテリー構成を1種類に統一する
- 可能な場合は、テレメトリ機能付きのスマートバッテリーを使用する
- バッテリーのローテーションと状態の追跡を行う
- 連続運用には、機体1台あたりバッテリー3個を目安に用意する

### 配電

- **PDB/PMS** — コンパニオンコンピュータ用の電源管理ボード
- **BEC** — Raspberry Piやサーボ向けの5V安定化電源
- **Jetsonの電源** — バッテリーからレギュレーター経由で直接供給（通常12V）

## 接続性

### セルラー：4G/5G + eSIM

各Jetsonはセルラーモデム経由で接続します：

| 仕様 | 値 |
|---------------|-------|
| **モデム** | Quectel RM520N-GLまたは同等品 |
| **バンド** | 4G LTE + 5G NR |
| **SIM** | OTAプロビジョニング対応eSIM |
| **インターフェース** | USB 3.0またはM.2 |

**eSIMの利点：**

- 大規模フリートでも物理SIMの差し替えが不要
- キャリアのリモートプロビジョニング
- カバレッジ最適化のためのキャリア切り替え
- サブスクリプションの一元管理

## 安全モデル

ドローン固有の安全機能は、複数のレベルで適用されます：

| レベル | 仕組み | 動作 |
|-------|-----------|----------|
| **RCオーバーライド** | ExpressLRS | パイロットは常に手動操縦が可能 |
| **フライトコントローラー** | PX4フェイルセーフ | RTL、着陸、ジオフェンスの適用 |
| **コンパニオン** | Vehicle Gateway | コマンド検証、安全チェック |
| **ネットワーク** | NATSは制御ループに一切関与しない | 監視専用で、飛行には影響しない |

安全アーキテクチャの全体については[安全モデル]({{< relref "/fleet/safety" >}})を参照してください。

## まとめ

| コンポーネント | 選定 | 理由 |
|-----------|-----------|-----------|
| **フレーム** | Holybro X500 V2 ARF | 実績があり、入手しやすく、保守しやすい |
| **FCU** | Pixhawk 6X | 冗長性、PX4 LTSサポート |
| **センサーコンパニオン** | Raspberry Pi 4/CM4 | コスト効率が高く、GPIOが豊富 |
| **AIコンパニオン** | Jetson Orin/Xavier | GPU推論、CUDAエコシステム |
| **RC** | ExpressLRS | オープンソース、長距離 |
| **テレメトリ** | SiK 915MHz | バックアップリンク、デバッグ |
| **電源** | 4S LiPo 5000mAh | フリートの標準化 |
| **セルラー** | 4G/5G + eSIM | OTAプロビジョニング、カバレッジ |
| **プロトコル** | MAVLink 2.0 | 業界標準、PX4ネイティブ |

## 購入方法

当社はハードウェアを販売していません。販売はパートナーが行います。**認定ドローンショップ**では、フリートインフラを含む完全なキットを提供できます。

**ドローンを購入される方へ：**
[認定パートナー]({{< relref "/partners" >}})から購入すると、以下が提供されます：
- すぐに接続できる設定済みのハードウェア
- 当社のマネージドインフラ用の認証情報
- 購入店によるローカルサポート

**ドローンショップの方へ：**
[パートナープログラムに参加]({{< relref "/partners/become-partner" >}})して、ハードウェア販売と合わせてフリートインフラを提供しましょう。
